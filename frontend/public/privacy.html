CardSync 개인정보처리방침

시행일: 2026년 11월 26일

CardSync(이하 "서비스")는 원문을 카드뉴스로 만들고 검수하는 웹 서비스입니다. 서비스는 이용자의 개인정보를 아래와 같이 처리합니다.

1. 수집하는 정보

  • 구글 로그인 시 구글이 제공하는 정보: 이메일 주소, 이름, 프로필 사진 주소, 구글 계정 식별자
  • 이용자가 올린 원문과 서비스가 만든 정보 묶음·카드·검사 결과
  • 서비스 운영 기록: 요청 시각, 요청 경로, 처리 결과

2. 이용 목적

  • 로그인과 본인 확인, 이용자별 작업 내용 저장·조회
  • 원문을 바탕으로 카드뉴스를 만들고 검사하는 기능 제공
  • 오류 확인과 서비스 개선

수집한 정보를 광고나 판매 목적으로 쓰지 않습니다.

3. 처리를 맡기는 곳

  • Supabase: 로그인 처리와 데이터 저장(서울 리전)
  • OpenAI: 카드 문구 생성과 검사를 위해 원문과 생성 내용을 API로 전달
  • Unsplash: 카드 이미지 검색을 위해 검색어 전달
  • Vercel, Amazon Web Services: 웹 화면과 서버 운영

4. 보관 기간과 삭제

정보는 이용자가 삭제를 요청하거나 서비스가 종료될 때까지 보관하며, 요청을 받으면 지체 없이 해당 계정의 정보와 작업 내용을 삭제합니다.

5. 이용자의 권리

이용자는 언제든지 자신의 정보 열람, 정정, 삭제, 처리 정지를 요청할 수 있습니다. 구글 계정 설정(myaccount.google.com/permissions)에서 CardSync의 접근 권한을 직접 해제할 수도 있습니다.
